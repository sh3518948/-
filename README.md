# -KOSPI 주식 데이터 분석 프로젝트

1. 프로젝트 개요

- 분석 기간: 2024.03.27 ~ 2026.09.02
- 분석 대상: 코스피 상장 종목
- 데이터 출처: 네이버 금융 기반 주식 HTML 데이터
- 산업분류 기준: KRICS 9개 섹터 (2026.10.30 기준 소급 적용)
- 목표: 2년 반 동안의 주식시장 변화와 업종별 특성을 9개 질문을 통해 분석

2. 진행 현황

질문| 분석 내용| 진행 상태
1| 시가총액 상위 30개 종목의 순위 변화| 그래프 초안 작성
2| 업종 간 주가수익률 격차 변화| 분석 및 시각화 진행 중
3| 업종 간 동조화| 그래프 초안 생성
4| 거래량과 주가의 선후행 관계| 그래프 초안 생성
5~9| 재무제표 관련 분석| 자료 검토 중

3. 작업 기록

2026.11.25 — 질문 1번 그래프 업로드

- 2024년과 2026년의 시가총액 상위 30개 종목 비교
- 종목별 시가총액과 순위 변동 표시
- 신규 진입 종목을 구분하는 NEW 표시 추가
- KRICS 섹터별 색상 적용
- 마우스 상호작용 기능 구현
- 향후 전체 슬라이드 디자인 통일 예정

4. 주요 분석 결과 (초안)

2024년 상위 30개 종목 중 20개가 2026년에도 상위 30위권을 유지했으며, 10개 종목이 교체되었다.

삼성전자와 SK하이닉스의 합산 시가총액이 상위 30개 종목 전체에서 차지하는 비중은 42.9%에서 64.0%로 상승했다.

※ 분석 결과 및 그래프는 검증과 디자인 수정에 따라 변경될 수 있음.
모든 질문에 대한 html을 별도로 제작 후 마무리 단계에서 통합 예정(수정편의성 목적)
